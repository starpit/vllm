vllm-rs

High-performance LLM inference, rewritten in Rust. Memory-safe, single-binary, zero Python runtime.

⚡

Fast Startup

Native binary starts in milliseconds. No interpreter, no JIT warmup, no import graph to resolve.

🛡

Memory Safety

Rust's ownership model eliminates data races, use-after-free, and buffer overflows at compile time.

📦

Single Binary

One statically-linked executable. No virtualenvs, no pip, no dependency hell. Just ./vllm serve.
